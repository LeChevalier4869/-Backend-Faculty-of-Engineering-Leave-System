# รายงานผลการทดสอบ Seed & การติดตั้งระบบใหม่ (Fresh Install)

- **วันที่ทดสอบ:** 2026-07-27
- **ผลรวม:** ✅ **ผ่านทั้งหมด** (มี 1 ข้อสังเกตด้านเวอร์ชันฐานข้อมูล — ไม่ใช่บั๊คของระบบ)
- **ขอบเขต:** จำลองการ deploy ระบบใหม่ตั้งแต่ฐานข้อมูลว่างเปล่า → seed → สร้างผู้ดูแลคนแรก → นำเข้าผู้ใช้จาก Excel

## สภาพแวดล้อมที่ใช้ทดสอบ

- ฐานข้อมูลทดสอบ **ใหม่แยกต่างหาก** (`eleave_test`, charset `utf8mb4`) บนเครื่อง local — **ไม่แตะฐานข้อมูล production**
- สร้าง schema ให้ตรงกับ migration ปลายทางทุกประการ
- ทดสอบ `prisma migrate deploy`, `node prisma/seed.js`, `npm run create-super-admin`, และ controller `uploadUserExcel` จริง (stub อีเมลกันส่งจริง)

## ข้อสังเกต (ต้องระวังตอน deploy จริง)

⚠️ **เวอร์ชันฐานข้อมูล:** migration `20260126122250_update_schema_to_latest` ใช้คำสั่ง
`ALTER TABLE ... RENAME INDEX` ซึ่งรองรับเฉพาะ **MySQL 8.0+ หรือ MariaDB 10.5+**

- เครื่องปลายทางต้องเป็น MySQL 8+ / MariaDB 10.5+ ไม่งั้น `npm run setup` (migrate deploy) จะล้มเหลว
- **ห้ามแก้ไฟล์ migration** ที่ apply ไปแล้วเพื่อเลี่ยงปัญหานี้ เพราะ Prisma checksum จะไม่ตรงกับ production
- Production ปัจจุบันไม่กระทบ (เป็น MySQL 8 และ migrate ผ่านแล้ว)
